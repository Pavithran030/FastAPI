# FastAPI

This repository contains small FastAPI learning examples that progressively cover:

- Basic route setup (`/home/runner/work/FastAPI/FastAPI/initialtest`)
- Pydantic model validation (`/home/runner/work/FastAPI/FastAPI/pydantic_data_validation`)
- GET and POST usage (`/home/runner/work/FastAPI/FastAPI/fetch_post`)
- PUT and DELETE operations (`/home/runner/work/FastAPI/FastAPI/delete_put`)
- SQLAlchemy database connection and CRUD persistence examples:
  - `/home/runner/work/FastAPI/FastAPI/db_connection`
  - `/home/runner/work/FastAPI/FastAPI/fetch_from_db`
  - `/home/runner/work/FastAPI/FastAPI/db_CRUD`
